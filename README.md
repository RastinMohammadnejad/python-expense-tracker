# Python Expense Tracker

A simple command-line expense tracker built with Python.

## Features

- Add expenses
- View expenses
- Delete expenses
- Show total expenses
- Store expenses in a JSON file
- Validate expense amounts
- Load and save expenses using separate functions

## Technologies

- Python
- JSON
- Git & GitHub

## Project Structure

```text
python-expense-tracker/
├── main.py
├── expense_manager.py
├── expenses.json
├── README.md
└── .gitignore
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/RastinMohammadnejad/python-expense-tracker.git
```

Open the project directory:

```bash
cd python-expense-tracker
```

Run the application:

```bash
python main.py
```
